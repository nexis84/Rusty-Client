# RustyBot - EVE Online Giveaway Tool

## What is RustyBot?

RustyBot is a desktop application for streamers running EVE Online giveaways on Twitch and Kick.com. It automates the entire giveaway workflow from entry collection to winner confirmation.

## Features

- **Multi-platform chat monitoring** - Monitors both Twitch and Kick.com chat simultaneously
- **Automated entry collection** - Users type a command (e.g., `!play`) to enter the draw
- **Animated winner selection** - Multiple animation styles including Hacking, Triglavian, Node Path, and more
- **Winner confirmation system** - Automatic confirmation with configurable timeouts
- **EVE Online integration** - Automatic EVE2Twitch IGN lookup and ESI validation
- **Prize management** - Configurable prize pools with Twitch chat poll support
- **Jackpot mode** - Special jackpot draws triggered by specific users
- **Customisable UI** - Draggable panels, multiple themes, adjustable font sizes
- **Sound effects** - Full audio support with individual volume controls
- **Hotkey support** - Configurable keyboard shortcuts for all actions

## Installation

### Professional Installer (Recommended)
1. Download `RustyBot_Setup_vX.X.X.0.exe` from the latest release
2. Run the installer
3. Launch RustyBot from the desktop shortcut

### Standalone ZIP
1. Download `RustyBot_vX.X.X_Standalone.zip` from the latest release
2. Extract to your preferred location
3. Run `Launcher.exe` to check for updates
4. Configure your Twitch credentials in `secure.env`

## Requirements

- Windows 10/11 (64-bit)
- Active internet connection for Twitch/Kick integration
- Python NOT required - standalone executable
